开盲盒 · 纯抽盒版（blindbox5）
=====================

花金币开盲盒 → 把手办放进展柜 → 所有手办全部放进展柜就通关（数量随配置自动变化）。
3D 手办用 Lux3D 预先生成，放进 models 文件夹即可；游戏运行时不调用 Lux3D API。
游戏由自带的 C++ 程序（blindbox-server）运行：网页、模型、规则计算、存档都由它负责，试玩不需要额外依赖；修改 C++ 源码后需要 C++ 编译器（下文有说明）。

团队开发（保存后自动更新）
--------------------------
macOS 双击「开发模式.command」，Windows 双击「开发模式.bat」。
首次需要 Node.js 22.12+ 和 C++ 编译器；会自动安装前端依赖并打开浏览器。
保持开发窗口运行，保存 server/src/game_config.cpp 后自动编译、重启并刷新当前网页。
保存 web/src/ 中的前端源码会自动更新；Git 拉取得到的源码修改也会触发。
开发存档为 data/dev-save.db，与试玩存档分开。初始金币改动对新开局生效，可点「重置进度」测试。
开发模式会常驻，结束开发时在开发窗口按 Ctrl+C；正常试玩仍用原「启动游戏」启动器。
GitHub 协作和安装说明见 README.md。

目录结构
--------
  启动游戏.bat              Windows：双击这个开始玩
  启动游戏.command          macOS 启动器
  blindbox-server.exe       游戏程序（Windows）
  blindbox-server-mac-*     游戏程序（macOS，arm64 = M 系列芯片，x64 = Intel）
  web/                      可编辑网页源码
  dist/                     启动器自动构建的游戏网页
  models/                   放 <手办id>.glb，例如 ms-01.glb；缺了自动用占位体
                            models/README.txt 列出所有文件名和是否已放入
  data/                     存档（第一次运行后出现；删掉 = 进度清零）
  server/                   C++ 源码（改游戏内容看 server/README.md）

------------------------------------------------
开始玩
------------------------------------------------
Windows：双击「启动游戏.bat」
  → 黑窗口里启动游戏并自动打开浏览器（http://127.0.0.1:8765/）
  → 关闭最后一个游戏网页后约 5 秒，服务器会自动退出，不用再按 Ctrl+C
  → 刷新页面、切到后台、最小化不会退出；多个标签页要全部关闭才退出
  第一次运行如果出现 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」。
  Windows 防火墙如果弹窗，选「取消」也没关系（只给本机用）。

macOS：右键「启动游戏.command」→ 打开
  关闭所有游戏网页后会自动退出；单独打开的 Terminal 窗口也会在结束后尝试关闭。
  （若提示无法打开：在「系统设置 → 隐私与安全性」里点「仍要打开」）

直接双击 index.html 只会看到「请双击 启动游戏.bat 运行」。

------------------------------------------------
怎么玩
------------------------------------------------
1. 「商店」里配置的盲盒开局都能买：
     深夜食堂 100 金币   打工动物 200 金币   怪奇家电 400 金币
     奶蛙一家 1000 金币
   开局金币以 server/src/game_config.cpp 的当前配置为准，已有存档保留原金币。
2. 开出手办后（可以拖动旋转）有三个按钮：
     放进展柜 / 放入仓库 / 卖掉      点空白处 = 放入仓库
   展柜里同一款只能放一个。
3. 「仓库」里的手办可以重新打开，再放进展柜或卖掉。
4. 「展柜」里的手办不能卖，点开只有「放入仓库」。
   展柜顶部显示收集进度（已收集数 / 总数）和每种盲盒的进度。
5. 所有配置的手办全部放进展柜 = 通关。通关画面会显示本次开了多少盒、用了多少时间。

卖价 = 稀有度基础价 × 盲盒倍率
  稀有度基础价：普通 30 / 稀有 80 / 史诗 250 / 隐藏 1000
  倍率：深夜食堂 ×1 / 打工动物 ×2 / 怪奇家电 ×4
防重复：每种盲盒里，同一稀有度优先开出没拥有过的（卖掉也算拥有过）。
破产补助：买不起最便宜的盲盒、仓库也空了时，自动发 200 金币（展柜里的不算，因为不能卖）。

------------------------------------------------
修改游戏内容（盲盒种类、手办、掉率、价格……）
------------------------------------------------
全部写在 server/src/game_config.cpp 一个文件里，中文注释说明了每一项。
保存后，直接双击根目录的「启动游戏.command」（Mac）或「启动游戏.bat」（Windows）。
启动器会自动检查源码变化 → 只编译改过的文件 → 检查配置 → 更新游戏程序 → 打开游戏。
没有变化时直接启动；配置写错会显示错误并停止，不会悄悄打开旧版。
重复启动会关闭这个游戏包的旧服务器。存档仍在本目录 data/，新增盲盒不需要删档。

修改源码后的首次编译需要编译器（已安装则不用再装）：
  macOS：终端运行 xcode-select --install，安装后重新双击启动器。
  Windows：安装 MSYS2 的 g++，或 Visual Studio 的“使用 C++ 的桌面开发”组件。
           启动器会自动查找常见安装位置，详见 server/README.md。
第一次较慢，后续只改 game_config.cpp 会复用其他代码和 SQLite 的编译缓存。

------------------------------------------------
放置自己的 Lux3D 模型
------------------------------------------------
文件放进 models/，文件名见 models/README.txt（默认 = 手办 id，例如 ms-01.glb）。
放好后刷新网页即可，不用重启、不用改代码。


【纯抽盒玩法】
导航只有“抽盲盒 / 仓库 / 展柜”，没有代抽、顾客任务、小店装扮或代币兑换。
每次开盒按该系列概率独立抽取，没有连续抽取保底。
隐藏款掉率：深夜食堂 1.5%，打工动物 3%，怪奇家电 4%，奶蛙一家 2%。
同系列、同稀有度优先开出没拥有过的款式；可在 game_config.cpp 关闭防重复。

【复制过来的旧存档】
金币、仓库、展柜、待安置手办和个人收藏记录保留。
旧进行中委托取消，个人垫款或旧保证金退回一次；顾客剩余预算不发给玩家。
保存后移除旧委托、代币和保底计数，不需要手动删档。
本目录的服务和存档与 blindbox 4 分开。
详细开发说明见 README.md，接口见 docs/api.md。
