开盲盒 · 试玩说明（v3）
=====================

花金币开盲盒 → 把手办放进展柜或卖掉 → 集齐系列拿奖励并解锁下一种盲盒。
3D 手办用 Lux3D 预先生成，放进 models 文件夹即可；游戏运行时不联网调用 API。

v3 新增：C++ 游戏服务器（blindbox-server.exe）
  · 开盒抽取、金币、仓库、展柜、存档、个人记录都由服务器计算和保存
  · 服务器同时提供网页和模型文件，评委电脑不用装任何东西
  · 服务器启动失败时自动退回单机模式（存档在浏览器里，两边存档分开）

目录结构
--------
  启动游戏.bat              Windows：双击这个开始玩
  启动游戏.command          macOS 启动器
  blindbox-server.exe       C++ 游戏服务器（Windows）
  blindbox-server-mac-*     C++ 游戏服务器（macOS，arm64 = M 系列芯片，x64 = Intel）
  index.html                游戏网页（也可以直接双击，作单机备用）
  index.modules.html/assets 多文件版网页
  items.json                单机备用模式的数值表（由服务器配置自动生成，不要手改）
  models/                   放 <手办id>.glb，例如 ms-01.glb；缺了自动占位
                            models/README.txt 列出所有文件名和是否已放入
  data/                     存档（第一次运行后出现；删掉 = 进度清零）
  server/                   C++ 服务器源码（改游戏内容看 server/README.md）
  staticserver.exe          单机备用的静态服务器
  启动游戏.ps1              Windows 备用启动脚本

------------------------------------------------
开始玩
------------------------------------------------
Windows：双击「启动游戏.bat」
  → 黑窗口里启动游戏服务器并自动打开浏览器（http://127.0.0.1:8765/）
  → 页面右上角显示「联网模式（C++ 后端）」
  → 关闭黑窗口 = 退出
  第一次运行如果出现 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」。
  Windows 防火墙如果弹窗，选「取消」也没关系（服务器只给本机用）。

macOS：右键「启动游戏.command」→ 打开
  （若提示无法打开：在「系统设置 → 隐私与安全性」里点「仍要打开」）

备用：直接双击 index.html（file:// 单机模式），点「导入模型文件夹」加载模型。

------------------------------------------------
修改游戏内容（盲盒种类、手办、掉率、价格……）
------------------------------------------------
全部写在 server/src/game_config.cpp 一个文件里，中文注释说明了每一项。
改完后双击 server/编译.bat（或 VS Code 里 Ctrl+Shift+B）重新编译，
它会自动更新本目录的 blindbox-server.exe 和 items.json。详见 server/README.md。

------------------------------------------------
放置自己的 Lux3D 模型
------------------------------------------------
文件放进 models/，文件名见 models/README.txt（默认 = 手办 id，例如 ms-01.glb）。
放好后刷新网页即可，不用重启、不用改代码。

怎么玩
------
1. 商店点「开盲盒」（100 金币）
2. 展示界面：拖动旋转；「放进展柜」或「卖掉」
3. 点空白处 → 进「仓库」，之后还能再打开选择
4. 展柜集齐一个系列 → 奖励并解锁下一系列；三个系列都集齐即通关
5. 「记录」页：展柜最高总价值、最快通关（联网模式）

保底：同一种盲盒连续 12 个没出隐藏款，第 12 个必出。
防重复：同一稀有度优先开出没拥有过的（卖掉也算拥有过）。
破产补助：钱不够、仓库和展柜都空了时，自动发 200 金币。
