# 开盲盒 设计文档 v1(小黑)

## 核心循环
金币买盲盒 → 开箱动画 → 得到手办 → 二选一:放进展柜 / 卖掉换金币 → 继续买盲盒。

## 目标
- 每个系列 7 个手办,全部放进展柜即"集齐",获得系列奖励并解锁下一个系列的盲盒。
- 第三个系列集齐即通关(Demo 终点),显示通关画面和"我的展柜"截图按钮,方便传播。

## 规则
- 开局 500 金币,盲盒 100 金币一个,只能买已解锁系列的盲盒。
- 抽取:先按稀有度掉率抽(普通 60% / 稀有 25% / 史诗 12% / 隐藏 3%),再在该系列同稀有度里抽(见防重复)。
- 保底:连续 12 个没出隐藏款,第 12 个必出隐藏款。
- 防重复:同一稀有度里优先开出还没拿到的,该稀有度集齐后才会出重复。
- 卖价:普通 30 / 稀有 80 / 史诗 250 / 隐藏 1000。单盒平均卖价 98,略低于盒价,光卖会慢慢亏。
- 系列奖励:深夜食堂 1500、打工动物 2500、怪奇家电 4000。主要收入来自集齐奖励。
- 展柜里的手办也能取出来卖,但会让该系列变回未集齐(已领过的奖励不收回,也不重复发)。
- 重复的手办只能卖或放进"仓库",展柜每格一个。
- 金币不够买盒且没有可卖的东西时,给一个"破产补助"200 金币,避免卡死。

## 界面(第一版)
1. 商店:系列盲盒列表、价格、当前金币。
2. 开箱(老板定):点一下盲盒 → 盒子弹开,手办弹出来 → 进入展示界面。
   - 展示界面:手办居中,鼠标拖动可自由旋转,背景颜色按稀有度,显示名字和稀有度。
   - 底部两个按钮:[放进展柜] [卖掉 +X 金币]。
   - 点空白处 = 关闭展示界面,手办自动进仓库,之后在仓库里还能再选放展柜或卖。
3. 仓库:开出来没处理的手办都在这里,每个都可以点开重新进入展示界面。
4. 展柜:按系列分行,未获得的显示剪影。

## 待调(玩起来再改)
- 掉率、卖价、奖励数值;20 抽保底是否太长。
- 一局时长目标:15 到 20 分钟通关,适合评委试玩。

## 后端(11-10,老板定)
- 单机游戏,没有二手市场、NPC 和玩家交易。"卖掉"就是按固定卖价卖给系统。
- C++ 后端编译成 exe,和游戏一起打包,在本机运行,同时提供网页和模型文件。
- 后端负责:开盒抽取(掉率、保底、防重复)、金币、仓库和展柜、存档。通关画面显示当次开盒数和用时。

## v4 改动(11-10,老板定,以本节为准,覆盖上文冲突内容)
1. 没有联机/单机之分:游戏只通过本机 C++ 后端运行;删掉单机备用逻辑和 items.json,game_config.cpp 是唯一配置。
2. 新开出的手办在展示界面有三个按钮:[放进展柜] [放入仓库] [卖掉];点空白处 = 放入仓库。
3. 展柜里的手办不能卖:点击进入展示界面,只有 [放入仓库] 一个按钮。只有仓库里的手办可以卖。
4. 三种盲盒开局全部开放,随意购买;删除解锁顺序和集齐奖励。21 个手办全部放进展柜 = 通关(保留通关画面)。
5. 盲盒分价位:深夜食堂 100、打工动物 200、怪奇家电 400。卖价 = 稀有度基础卖价 × 该系列卖价倍率(默认 1 / 2 / 4,写在 game_config.cpp,可改)。
- 保底(12 盒)和防重复按每个系列分别计算。
- 收入只剩卖东西,单盒平均卖价 = 盒价的 98%;破产补助 200 保留,防止卡死。

## v4.1 改动(11-10)
- 去掉昵称和创建玩家步骤,打开游戏直接读取本机唯一存档,不需要名字。
- 去掉「记录」页和本机榜单;相关接口一并删除。
- 通关画面仍显示当次开了多少盒、用了多少时间。
- 游戏规则、掉率和价格与 v4 相同。
