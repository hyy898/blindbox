# Lux3D 手办生成提示词(21 个)

## 统一设置
- 模式:文字生成 3D(text-to-3d),版本 G1(要快可用 G1-Turbo 试稿)
- 面数 faceCount:30000(网页里放 21 个模型不卡;隐藏款可给 50000)
- 输出格式:glb,开启 PBR 材质
- 文件命名:用手办 id,例如 `ms-01.glb`,放进 `assets/models/`
- 每个提示词 = 主体描述 + 统一风格尾巴,保证 21 个风格一致

统一风格尾巴(每条都已拼好,下面直接复制即可):
`, cute chibi blind box vinyl toy figurine, Pop Mart style, smooth glossy plastic, soft pastel colors, big head small body, full body, single object, standing on a small round base, centered, no background`

## 生成流程(给报告用)
1. 每个手办先用 G1-Turbo 跑一版试稿,看造型对不对;不满意就改提示词再跑。
2. 定稿后用 G1 + 上面的统一设置出正式 GLB。
3. 每个模型截图三张:提示词、生成结果、(如有)改提示词前后对比,存到 `docs/screenshots/<id>/`,报告直接用。
4. 下载链接 2 小时过期,出完马上下载并按 id 改名。
5. 交给大黑统一缩放和朝向后放进游戏。
6. 并发上限免费账号 5 个,一次提交不超过 5 个任务。
