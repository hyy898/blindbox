## 资源与限制

模型仍为 **6/31 款到位**：`ms-01～05`、`mf-10`。缺失 25 款：`ms-06～07`、`wa-01～07`、`wd-01～07`、`mf-01～09`；逐款名称见[资源清单](v2-resource-manifest.md)。缺失项没有使用其他模型冒充，首页四张 PNG 仅为系列插画。

本轮包装采用 CSS 盒盖与折面配合真实 GLB，未实现物理纸盒折叠；没有新增“新邻居”联动。手机验证来自桌面浏览器的手机尺寸，尚非 iPhone／Android 真机性能验收。原有规则仍无连续次数保底，未自行新增数值或前端计数器。

主要文件：`web/src/main.js`、`box-gesture.js`、`experience.css`、`viewer.js/css`、`storefront.js/css`、`cabinet.js/css`、`cabinet-photo.js`，以及相关测试和 `blindbox/dist/` 构建产物。最终本地提交号见交付消息。
