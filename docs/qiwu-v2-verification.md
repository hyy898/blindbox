
## 视觉与交互验收

桌面已移除“大标题＋左展示右购买栏”。四格后方货架直接选择系列；连续木柜台有台面、前沿、暗部与接触阴影；三只宽矮纸盒独立摆放，选中盒子移到中央并靠前。主要按钮位于中心盒下方，价格和系列信息放在小牌，下面是读取真实收藏的快捷条。

选中的纸盒 DOM 节点直接移入拆封台，再延续到展开阶段。横向拖封条、点击按钮及键盘替代均保留；四秒展开后进入系列三维展台。结果页主要面积用于真实模型，右侧为藏品与安置操作。抽取先保存，动画和加载分别处理。

展柜是一座共用木柜体与三个固定位置。默认没有编辑表单，点铭牌后只展开一个编辑区。打开／关闭编辑与恢复正面复用原 viewer；转动模型同步滑块，陈列角度与位置持久化。库存转移仍由原接口完成。

390×844 下改为系列标签、当前货架、主盒、柜台操作区。实际检查页面宽度为 390，无水平溢出；主按钮位于 y=569–617，收藏快捷条在首屏可见。手机展柜分两层并允许纵向浏览，编辑区在选中后滚入可见区域。

本轮浏览器验证修复了结果画布因百分比高度不断撑大、展柜编辑重复加载、滑块不同步，以及静止 WebGL 画面偶尔为空的问题。查看器现在仅在尺寸变化时调整绘制缓冲，首帧实际绘制后才显示 ready，并保留按需绘制的最后一帧；桌面、手机和静止后截图复验可见真实模型。最后控制台检查无错误或警告。

## 源码与保底

新 C++ 源码已隔离编译；与现行程序的完整配置一致。经济检查 157 项、两份程序各 73 项 HTTP／SQLite 检查通过；相同随机种子下 80 次抽取及其后续操作共 330 个响应一致。二进制哈希不同，不能据此声称字节级复现；本轮继续使用原稳定服务程序。

当前没有连续次数保底或软保底。每次先独立抽稀有度，再在同系列、同稀有度中优先从未拥有款；范围依据持久化 `everOwned`。全部曾拥有后恢复完整候选池，出售不清除历史，刷新不重置。`boxesOpened` 是全局成功抽盒总数，不是保底计数。具体新增保证目标、阈值、累计范围、重置条件和旧档迁移仍待团队确定，本轮没有改数值或添加前端保底条。完整对应关系见 [后端审计](v2-backend-audit.md)。
