# 天地盖包装改造 · 2026-11-18

当前状态：实现及主要回归已完成，功能分支 `feat/box-redesign`。完整画幅连续录屏与 Safari 检查尚待补验，不能把本记录当作全部验收通过。

## 实现与兼容

- 根据交付包的 9 页 PDF、设计说明、配色几何 JSON、SVG 及离线动作原型实现。SVG 原样保存在 `web/public/packaging/`，JSON 保存在 `web/src/packaging-design.json`。四字名称是路径，不依赖中文字体加载。
- 共用 Three.js 程序几何：240:216:180 比例，184 盒身与 32 浅盖，四面不透明盒壁、底板、独立浅盖、纸张微纹理与接触阴影。正面仅图案与四字系列名，封签仅“奇”；顶面与侧面没有额外印字。
- 首页到拆封移动同一个画布与盒体；抬盖、盒身向下退出、模型显露共用同一相机和深度遮挡。模型按朝向后的包围盒适配盒内空间。展台在盒身退到下方后出现，禁止半透明盒面穿过模型。
- 演出逻辑时间为 2600ms，2280ms 后显示名称和操作；模型未准备好时停在 260ms，盖子闭合。减少动效约 200ms，仍保留明确加载状态。跳过只改变演出，不抽取。失效资源重试继续同一结果。
- 桌面三个盒子，侧盒为中心盒的 0.84 倍；390px 布局只显示主盒。按完整投影调整位置，桌面铭牌与盒顶约 16px、手机约 22px 间距，盒底落在台面范围内。
- 沿用现有双击识别与结算入口；选盒和进入拆封不扣款，向上揭封达到 86px 或直接拆封才结算。原价格、奖池、模型身份、库存、重复款处理、缓存、存档、合影及启动器不变。未改后端或数据库结构。
- 修复测试中发现的画布移动后仍停留在闭盒帧的问题：演出每帧直接提交当前姿态；另提高深色展台上“回到正面”的对比度。

## 存档保护

开始时本地和 `origin/main` 均为 `99dea338548571918955d8d716c31a3975465c71`，提交前重新获取远程仍一致。原工作区仅有已存在的 `blindbox/data/dev-save.db-shm` 修改，保留且不提交。

真实 SQLite 存档通过 SQLite backup API 备份到忽略目录 `.local/backups/box-redesign-20261118/`。本轮 UI 操作只使用 `npm start -- --isolated` 创建的临时存档。正式及开发数据库 `.db`、`.db-wal` 的 SHA-256 与开始时一致；只读备份可能触动共享内存锁文件，不把这类运行文件加入提交。

当前实际奖池仍是四系列、28 款，全部模型文件已到位。503/404 是隔离代理模拟，没有删除或替换任何正式模型；没有修改任何价格、概率或保底规则。
