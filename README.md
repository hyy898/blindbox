# 奇物百货

Aholo 3D AI 黑客松盲盒项目的“奇物百货”店铺前端，当前为第二轮本地功能版本。团队使用 GPT 生成藏品图片，再通过 Aholo Lux3D 制作模型；本仓库负责挑盒、拆封、收藏和展柜体验。

本轮首页改为后方四格系列货架、前方连续暖木柜台和三只米白纸盒，中心盒下方放置主要操作，柜台小牌显示真实价格，下沿提供收藏快捷入口。手机使用当前系列货架、主盒与柜台操作区重新排布。展柜采用三个固定陈列位置，选中铭牌后才显示编辑控件。保留第一版的业务流程、数据保护、四个系列与 31 款藏品身份，以及原服务中的价格、抽取规则和 SQLite 收藏存档。

**owner 本轮补传了 6 款真实模型，还有 25 款缺失。** 已到位的是深夜食堂 `ms-01`～`ms-05` 和奶蛙一家 `mf-10`，已逐款验证 GLB 纹理、尺度与朝向，并生成真实模型透明缩略图。结果页与展柜按需加载同一藏品的 GLB；缺失项明确显示“模型待补齐”。奶蛙系列完整保留。

首页四格货架使用本轮生成的四张透明手绘风 PNG，全部标为“系列示意”，仅表达系列气质，不代表实际奖品。货架中不使用模型缩略图或 SVG 替代插画；下沿收藏快捷条与收藏列表仍根据已获得藏品显示对应真实模型缩略图。实际抽取身份、结果页及展柜继续使用服务数据和对应 GLB。

补传的 C++ 源码已与现行 macOS Apple Silicon 服务核对配置、业务响应和存档兼容性；**正常启动仍使用原有二进制**，没有替换数据库或改变概率、价格、重复款处理。当前服务没有连续次数保底，只有同系列、同稀有度的历史防重复；本轮没有自行增加保底数值或前端计数器。

## 本地体验

需要 Node.js 22.12 或更高版本。仓库提供 macOS Apple Silicon、macOS Intel 和 Windows 的本机服务程序；本轮实际验证使用 macOS Apple Silicon。

在仓库根目录执行：

```sh
npm ci
npm run build
npm start
```

打开终端打印的地址，通常是 <http://127.0.0.1:8765/>；端口已占用时服务会尝试后续端口。保持启动窗口运行，按 `Ctrl+C` 停止。

macOS 也可右键打开根目录的 `启动奇物百货.command`，它会自动安装缺失依赖、构建并打开浏览器。旧的 `blindbox/启动游戏.command` 在完整源码目录中会转到新入口。

正常启动沿用 `blindbox/data/blindbox-save.db`。需要体验或测试而不触碰已有收藏时，使用：

```sh
npm start -- --isolated
```

隔离模式每次新建一份临时存档，启动日志会打印完整路径。它不会读取、重置或覆盖正常存档。

## 体验流程

1. 点击后方系列货架，再挑柜台上的包装盒，点击“挑这一盒”；选盒不扣金币。
2. 向右拖动封条，或用“拆开看看”按钮／键盘开封。实际扣费与结果由原服务一次性保存。
3. 包装展开成小展台，约 4 秒后揭晓；可跳过动画。关闭、刷新或模型重试都继续保留同一结果。
4. 将藏品收进收藏仓库，或按原有规则收入展柜。同款展柜最多一件，重复实物可留在仓库。
5. 在“我的展柜”点击一个位置的铭牌，从已收入展柜的款式中选择并调整朝向；更换位置不会复制库存或再次扣费。

声音默认关闭；“偏好与店内说明”中可开启声音、减少动效并查看真实奖池概率。陈列位置、朝向和偏好保存在当前浏览器；金币与藏品保存在本机 SQLite，两者分工独立。

## 开发与检查

沿用 Vanilla JavaScript、Three.js 与 Vite。当前前端源码位于根目录 `web/`，构建输出到 `blindbox/dist/`。owner 补传中的旧前端位于 `blindbox/web/`，保留供参考，不应覆盖当前前端。原生服务程序、游戏规则和存档格式没有替换；新源码位于 `blindbox/server/`。

```sh
npm test          # 请求互斥、未知结果恢复、陈旧结果防护等客户端检查
npm run test:api  # 临时存档上的真实服务检查，不调用原存档
npm run build    # 生成供本机服务使用的网页
```

开发时先启动本机服务，再在另一个终端执行 `npm run dev`。Vite 默认将 `/api` 和 `/models` 转发到 `http://127.0.0.1:8765`；若服务使用其他端口，请相应修改 `vite.config.js`。

## 接入团队模型

将模型放入 `blindbox/models/`，文件名与 `/api/config` 的 `item.model` 一致：深夜食堂 `ms-01.glb`～`ms-07.glb`、打工动物 `wa-01.glb`～`wa-07.glb`、怪奇家电 `wd-01.glb`～`wd-07.glb`、奶蛙一家 `mf-01.glb`～`mf-10.glb`。优先使用纹理内嵌的 GLB；当前未配置 Draco／KTX2 解码器。

模型到位后可在原藏品详情点击“检查模型更新”，无需重新抽盒。首次显示不会为已知缺失项反复请求文件；手动重试仍会访问该藏品原模型地址。新增资源后应逐款核对实际外观、中心、比例、纹理与移动设备性能，并更新 `web/src/assets.js` 和资源清单；不要只用文件存在与否判断 3D 验收完成。

运行 `node scripts/render-thumbnails.mjs` 可打开 <http://127.0.0.1:5197/> 资源工作台。它不连接游戏 API 或存档；保存按钮会把对应真实 GLB 的 512×512 透明 PNG 写到 `web/public/thumbnails/`。本轮原始模型约 9–20 MB，尚未压缩；首页货架用系列插画、收藏快捷条用真实缩略图，避免同时加载全部模型。

空木格素材只负责木材、灯光与空间背景。系列文字、价格、按钮、可选纸盒、抽取结果和收藏数量均由真实页面组件与数据渲染；没有把整张概念图当作页面。
